# What Changed in Mermaid Chart

## Mermaid Chart now requires sign-in

Sign in with a free Mermaid Chart account to use this extension, including:

- Diagram preview, creation, and editing
- Cloud sync and team collaboration
- AI generation, improvement, and repair
- Pull request and Mermaid Sync review tools

Your existing sign-in flow and authentication options have not changed.

## Want local preview without an account?

Install the **[Mermaid Preview](https://marketplace.visualstudio.com/items?itemName=vstirbu.vscode-mermaid-preview)** extension for local Mermaid preview and export without signing in.
